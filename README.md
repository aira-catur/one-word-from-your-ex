A deterministic Python program (standard library only, no network) that writes exactly one word — the word an ex would use to describe the entrant — with no extra newline, to `entry.txt` in `MAKEFUN_OUTPUT_DIR` (or `/output`).

Run it:

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
